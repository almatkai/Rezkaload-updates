# Rezkaload updates

Публичный канал готовых **подписанных обновлений Rezkaload для macOS**. В этом репозитории нет исходников приложения — они остаются приватными.

## Скачать

[Скачать последнюю версию Rezkaload](https://github.com/almatkai/Rezkaload-updates/releases/latest)

Архив содержит `Rezkaload.app`. Поддерживаются macOS 14.4+ и Mac с Apple Silicon/Intel.

Закройте старое приложение, распакуйте архив и замените Rezkaload.app в «Программах».

## Обновлять из приложения

**Rezkaload → Проверить обновления…** — скачать и установить новую версию без браузера и входа в GitHub.

Если используется версия до 2.2.1, один раз установите свежий билд вручную: старые версии использовали закрытый адрес обновлений. Затем обновления работают через это меню.

Приложение подписано Apple Development, но не нотарифицировано Apple; при первом запуске Gatekeeper может потребовать подтверждения открытия в «Системные настройки → Конфиденциальность и безопасность».

## Содержимое релиза

- `Rezkaload-vX.Y.Z.zip` — готовое приложение.
- `appcast.xml` — подписанный список обновлений для Sparkle.
- `*.sha256` — контрольная сумма архива.

И список обновлений, и архив проверяются криптографически. Приватные ключи, пользовательские данные и GitHub-токены здесь не публикуются. Автоматические архивы «Source code» GitHub содержат только документацию этого репозитория, не код приложения.
